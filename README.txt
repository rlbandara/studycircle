StudyCircle (NSBM Web and Mobile Application Development project)

1. Copy this whole folder to C:\xampp\htdocs\studycircle
   (index.php must be directly inside that folder)
2. Start Apache and MySQL in the XAMPP Control Panel
3. Open http://localhost/phpmyadmin > Import > choose database.sql > Go
4. Open http://localhost/studycircle
